# 📚 단어 테스트 웹사이트 기획안

## 1. 프로젝트 개요

엑셀(CSV/XLSX)로 정리된 영어/중국어 단어를 웹에 올려 간편하게 플래시카드 방식으로 단어 테스트를 할 수 있는 **SPA(Single Page Application)** 웹사이트.

---

## 2. 지원 단어 포맷

### 🇺🇸 영어
| A열 (단어) | B열 (뜻) |
|---|---|
| apple | 사과 |
| run | 달리다 |

### 🇨🇳 중국어
| A열 (한자) | B열 (병음) | C열 (뜻) |
|---|---|---|
| 苹果 | píngguǒ | 사과 |
| 跑步 | pǎobù | 달리다 |

> 포맷은 첫 행(헤더)이 없는 순수 데이터로 입력을 권장  
> (헤더가 있어도 자동 감지해서 건너뜀)

---

## 3. 주요 기능

### 3-1. 데이터 입력 방법 (2가지 택1)
1. **인라인 스프레드시트** : 웹 페이지 내 엑셀처럼 보이는 테이블에 직접 붙여넣기(Ctrl+V)  
   - 다른 엑셀 파일에서 셀 선택 후 복붙하면 탭/줄바꿈 구분으로 자동 파싱  
   - 행 추가/삭제, 직접 입력 가능  
2. **파일 업로드** : `.xlsx` / `.csv` 파일 드래그앤드롭 또는 버튼 클릭 업로드

### 3-2. 단어 모드 감지
- 열이 2개 → 영어 모드 자동 인식
- 열이 3개 → 중국어 모드 자동 인식
- 사용자가 수동으로 모드 전환 가능

### 3-3. 테스트 방식 — 플래시카드 (메인)
1. 단어 목록 무작위 셔플
2. 카드 앞면 표시 : **단어(영어)** 또는 **한자(중국어)**
   - 카드가 뜨는 동시에 **TTS 자동 재생** (Web Speech API)
   - 🔊 버튼으로 언제든 재발음 가능
   - 영어 : `en-US` 음성 / 중국어 : `zh-CN` 음성 자동 선택
3. 카드 아래 **답 입력 텍스트박스** 표시 (뜻 직접 입력, 선택 사항)
4. **[확인하기]** 버튼 클릭
   - 카드 뒤집기 애니메이션
   - 뒷면에 **해당 행의 모든 데이터** 표시 (영어: 단어+뜻 / 중국어: 한자+병음+뜻)
   - 사용자가 입력한 답을 함께 표시 (자동 채점 없음, 사용자가 직접 눈으로 비교)
5. 확인 후 버튼 2개 :
   - **[다음 단어 →]** : 그냥 넘어가기
   - **[오답노트 추가 📝]** : 사용자가 스스로 판단해서 오답노트에 추가
6. 모든 카드 완료 시 결과 화면

### 3-4. TTS 상세 스펙
- 브라우저 내장 Web Speech API 사용 (무료, 별도 키 불필요)
- 지원 음성 : 영어(`en-US`), 중국어(`zh-CN`), 한국어(`ko-KR`)
- 카드 등장 시 자동 재생 (설정에서 on/off 가능)
- 재생 속도 조절 (0.5x / 1.0x / 1.5x)
- 중국어는 한자 기준으로 TTS 재생 (병음 미사용, 브라우저가 한자 직접 읽음)

### 3-5. 오답노트 기능
- 테스트 중 **[오답노트 추가 📝]** 버튼을 누른 단어들만 저장 (사용자 수동 선택)
- 자동 채점/자동 추가 없음 — 완전히 사용자 판단에 맡김
- 결과 화면에서 오답노트 목록 미리보기
- **[오답노트 엑셀 다운로드]** 버튼 → SheetJS로 `.xlsx` 파일 생성 후 다운로드
  - 다운로드 파일명 : `오답노트_YYYYMMDD.xlsx`
  - 입력 포맷 그대로 유지 (영어 2열, 중국어 3열)

### 3-6. 세션 관리
- 오늘의 학습량(카드 수) 설정
- 틀린 단어만 모아서 재시험
- 로컬스토리지에 오답노트 임시 저장 (브라우저 닫아도 유지)

## 4. 화면 구성 (페이지 흐름)

```
[① 홈/데이터 입력]
      ↓
[② 설정] (TTS on/off, 재생속도, 카드 수 선택)
      ↓
[③ 테스트]
  카드 표시 → TTS 자동 재생
      ↓
  답 입력 텍스트박스
      ↓
  [확인하기] 버튼 → 카드 뒤집기 + 채점 결과
      ↓
  [다음 단어] or [오답노트 추가]
      ↓
[④ 결과] (정답률, 오답 목록, 오답노트 엑셀 다운로드)
```

### ① 홈/데이터 입력 화면
- 상단 : 로고 + 사이트명
- 좌측 탭 : [스프레드시트 입력] / [파일 업로드]
- 스프레드시트 : 엑셀처럼 보이는 그리드 (handsontable 또는 순수 구현)
  - 헤더 행에 컬럼 가이드 표시 ("단어/한자", "뜻/병음", "뜻")
  - Ctrl+V로 엑셀 데이터 한번에 붙여넣기 지원
  - 행 수 동적 확장
- 하단 : [테스트 시작] 버튼

### ② 설정 화면 (모달 또는 별도 화면)
- 언어 모드 : 영어 / 중국어
- 테스트 방식 : 플래시카드 / 타이핑
- 앞면에 표시할 것 : 단어 → 뜻 / 뜻 → 단어
- 카드 수 제한 여부

### ③ 테스트 화면
- 상단 : 진행 표시줄 (예: 7 / 30) + 정답률 실시간 표시
- 중앙 : 대형 플래시카드 (CSS 3D transform 뒤집기)
  - 앞면 : 단어/한자 + 🔊 TTS 버튼
  - 뒷면 : 정답 + 사용자 입력 답 비교 + ✅/❌
- 카드 아래 : 답 입력 텍스트박스 + [확인하기] 버튼
- 확인 후 : [다음 단어 →] [오답노트 추가 📝] 버튼

### ④ 결과 화면
- 정답률 도넛 차트
- 맞힌 단어 / 틀린 단어 목록
- 오답노트 단어 목록 미리보기 테이블
- **[📥 오답노트 엑셀 다운로드]** 버튼 (오답노트가 1개 이상일 때 활성화)
- [오답만 다시 테스트] [처음으로] 버튼

## 5. 기술 스택

| 구분 | 선택 | 이유 |
|---|---|---|
| 프레임워크 | 순수 HTML + Vanilla JS | 별도 서버 불필요, 가볍고 빠름 |
| 스타일 | Vanilla CSS | 자유로운 커스텀, 종속성 없음 |
| 엑셀 파싱 | SheetJS(xlsx.js) CDN | XLSX/CSV 모두 지원 |
| 스프레드시트 UI | 직접 구현 (contenteditable table) | 가벼운 grid로 충분 |
| 차트 | Chart.js CDN | 가볍고 도넛 차트 지원 |
| 배포 | GitHub Pages / Netlify Drop | 백엔드 불필요 |

## 6. 개선 제안 (기존 아이디어 대비)

| 기존 아이디어 | 개선 제안 | 이유 |
|---|---|---|
| 단순 정답 확인 | **뜻 직접 입력 → 확인하기 → 정답 비교** | 능동적 회상(Active Recall) 효과 |
| 알았다/몰랐다 버튼 | 자동 채점 + 오답노트 수동 추가 선택 | 사용자 자율성 + 빠른 진행 |
| 순서 고정 무작위 | 가중치 랜덤 (틀린 단어 더 자주 출제) | 에빙하우스 망각곡선 반영 |
| - | **TTS 카드 자동 발음** (Web Speech API) | 추가 비용 없이 발음 학습 |
| 단일 포맷 | 2열/3열 자동 감지 | 사용 편의성 향상 |
| - | **오답노트 엑셀 다운로드** (SheetJS) | 오프라인 복습 연계 |
| - | 다크모드 지원 | UX 향상 |
