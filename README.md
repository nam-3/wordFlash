# ⚡ WordFlash — 단어 테스트 웹앱

엑셀 또는 CSV로 정리한 단어장을 웹에서 바로 불러와 플래시카드 방식으로 학습할 수 있는 정적 웹앱입니다.  
영어, 중국어, 일본어 단어 데이터를 입력하고, TTS 발음을 들으며 테스트한 뒤 오답노트를 엑셀 파일로 다운로드할 수 있습니다.

> 배포 주소: https://wordflash.pages.dev/

---

## 📌 프로젝트 개요

WordFlash는 단어장을 엑셀로 정리해두고도 실제 테스트나 복습에 활용하기 어렵다는 문제에서 시작한 프로젝트입니다.

친구와 함께 어학 시험을 준비하면서, 엑셀에 정리한 단어 데이터를 그대로 활용해 더 쉽게 단어 테스트를 할 수 있는 웹사이트를 만들고자 했습니다.

이 프로젝트는 별도의 백엔드 서버 없이 브라우저에서 동작하는 **SPA(Single Page Application)** 형태로 제작되었으며, Cloudflare Pages를 통해 배포했습니다.

---

## 🎯 프로젝트 목표

- 엑셀 또는 CSV 단어장을 웹에서 바로 불러와 테스트할 수 있게 만들기
- 단어의 발음을 TTS로 들으면서 학습할 수 있게 만들기
- 틀렸거나 다시 보고 싶은 단어를 오답노트로 따로 정리하기
- 오답노트를 다시 엑셀 파일로 다운로드할 수 있게 만들기
- 학생들이 별도 설치 없이 쉽고 편하게 사용할 수 있는 단어 테스트 사이트 만들기

## ✨ 주요 기능

### 1. 스프레드시트 입력

웹 페이지 안의 표에 직접 데이터를 입력하거나, 엑셀에서 복사한 데이터를 그대로 붙여넣을 수 있습니다.

- 직접 입력 가능
- Ctrl+C / Ctrl+V 붙여넣기 지원
- 행 추가 및 초기화 지원
- 언어 모드 선택 가능

### 2. 파일 업로드

`.xlsx`, `.xls`, `.csv` 파일을 업로드하여 단어 데이터를 불러올 수 있습니다.

- 드래그 앤 드롭 업로드
- 파일 선택 업로드
- 업로드된 파일의 행 수 표시
- 정해진 데이터 포맷 기반 파싱

### 3. 플래시카드 테스트

입력한 단어를 무작위로 섞어 플래시카드 방식으로 테스트합니다.

- 카드 앞면에 단어 표시
- 카드 등장 시 TTS 자동 재생
- 답 입력 후 확인하기
- 카드 뒤집기 애니메이션
- 정답 데이터와 내 답안 비교
- 다음 단어로 이동
- 오답노트 수동 추가

### 4. TTS 발음 지원

브라우저 내장 Web Speech API를 사용해 단어 발음을 재생합니다.

| 언어 | TTS 언어 코드 |
|---|---|
| 영어 | `en-US` |
| 중국어 | `zh-CN` |
| 일본어 | `ja-JP` |

TTS 기능은 별도의 API Key 없이 브라우저에서 동작합니다.

### 5. 오답노트

테스트 중 사용자가 직접 오답노트에 추가한 단어를 저장합니다.

- 자동 채점 없음
- 사용자가 직접 판단하여 오답노트 추가
- 결과 화면에서 오답노트 목록 확인
- 오답노트 엑셀 다운로드 지원

## 🧾 지원 데이터 포맷

데이터는 정해진 형식에 맞춰 입력해야 합니다.  
첫 행에 헤더가 없어도 사용할 수 있도록 순수 데이터 입력을 권장합니다.

### 🇺🇸 영어

| A열 | B열 |
|---|---|
| 단어 / Word | 뜻 / Meaning |

예시:

| 단어 / Word | 뜻 / Meaning |
|---|---|
| apple | 사과 |
| run | 달리다 |
| study | 공부하다 |

---

### 🇨🇳 중국어

| A열 | B열 | C열 |
|---|---|---|
| 한자 | 병음 / Pinyin | 뜻 / Meaning |

예시:

| 한자 | 병음 / Pinyin | 뜻 / Meaning |
|---|---|---|
| 苹果 | píngguǒ | 사과 |
| 学习 | xuéxí | 공부하다 |
| 朋友 | péngyǒu | 친구 |

---

### 🇯🇵 일본어

| A열 | B열 | C열 | D열 |
|---|---|---|---|
| 한자 / 단어 | 히라가나 | 가타카나 | 뜻 / Meaning |

예시:

| 한자 / 단어 | 히라가나 | 가타카나 | 뜻 / Meaning |
|---|---|---|---|
| 学校 | がっこう | ガッコウ | 학교 / school |
| 先生 | せんせい | センセイ | 선생님 / teacher |
| 食べる | たべる | タベル | 먹다 / to eat |

## 📁 파일 구조

```text
sentence/
├── index.html          # 메인 HTML
├── style.css           # 전체 스타일
├── app.js              # 앱 상태 관리 및 화면 전환
├── spreadsheet.js      # 스프레드시트 입력 컴포넌트
├── flashcard.js        # 플래시카드 테스트 및 TTS 처리
├── parser.js           # XLSX / CSV / 클립보드 파싱 유틸
└── PLAN.md             # 프로젝트 기획 문서
```

## 🚀 실행 방법

별도의 서버가 필요 없는 정적 웹앱입니다.

### 로컬 실행

프로젝트 폴더에서 `index.html` 파일을 브라우저로 열면 실행할 수 있습니다.

```text
index.html
```

또는 VS Code의 Live Server 같은 확장 프로그램을 사용해 실행할 수 있습니다.

## 📝 프로젝트 회고

친구와 함께 어학 시험을 준비하면서, 단어 테스트가 더 편했으면 좋겠다는 생각에서 시작한 프로젝트입니다.

평소 엑셀로 단어를 정리해두는 경우가 많기 때문에, 이미 정리한 데이터를 그대로 웹에서 테스트할 수 있다면 학습 효율이 더 좋아질 것이라고 생각했습니다.

웹사이트 제작은 Antigravity IDE를 활용해 Claude와 함께 기획 및 구현했으며, 서버 없이 배포할 수 있도록 정적 웹앱 구조로 제작했습니다.
